# Flatpak build notes

The manifest is fully pinned: pdfium chromium/8165, espeak-ng 1.52.0,
tesseract 5.5.4 (+ leptonica 1.85.0), poppler 25.10.0, ffmpeg 7.1, and the
app's own Cargo.lock via `cargo-sources.json` (948 vendored sources,
generated by `flatpak-cargo-generator.py`).

One exception: the **onnxruntime** module sources a local archive of the
official 1.30.0 release layout (`dist/flatpak-sources/…`, built from a
verified install) because `github.com/microsoft/*` is unreachable from
some networks. CI on GitHub runners should swap that source to the
upstream URL and pin its sha256:

```
https://github.com/microsoft/onnxruntime/releases/download/v1.30.0/onnxruntime-linux-x64-1.30.0.tgz
```

## Build (locally, no sudo — Builder as a flatpak)

```bash
flatpak install --user flathub org.flatpak.Builder
flatpak run --command=flatpak-builder org.flatpak.Builder --force-clean \
    --default-branch=main build-dir packaging/flatpak/io.github.thesagezm.Speechnotes.yml
```

Or with the distro package: `sudo apt install flatpak-builder`, then plain
`flatpak-builder …`.

With `org.flatpak.Builder` the SDK it needs (`org.freedesktop.Sdk 26.08`)
installs alongside; the app itself builds against `org.gnome.Sdk 48` (plus
the rust-stable SDK extension), all fetched on first build.

## Install, run, bundle

```bash
flatpak-builder --force-clean --install --user build \
    packaging/flatpak/io.github.thesagezm.Speechnotes.yml
flatpak run io.github.thesagezm.Speechnotes --version

# single-file bundle for the GitHub release
flatpak build-bundle ~/.local/share/flatpak/repo \
    Speechnotes-0.1.0-alpha.1-x86_64.flatpak \
    io.github.thesagezm.Speechnotes --runtime-repo=https://flathub.org/repo/flathub.flatpakrepo
```

## Sandbox notes

- `$XDG_DATA_HOME` inside the sandbox is the app's own home, so the library
  lands in `~/.var/app/io.github.thesagezm.Speechnotes/data/speechnotes/`.
- The bundled libraries install to `/app/lib`; the manifest passes
  `--env=ORT_DYLIB_PATH=/app/lib/libonnxruntime.so` and
  `--env=SPEECHNOTES_PDFIUM_LIB=/app/lib/libpdfium.so`, which the app's
  dylib lookups check first — no patching needed.
- The app module sources the **git tag** `v0.1.0-alpha.1` (clean tree, no
  build artifacts); regenerate `cargo-sources.json` with
  `flatpak-cargo-generator.py Cargo.lock -o cargo-sources.json` after any
  dependency change.
